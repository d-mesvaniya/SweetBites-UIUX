# 🍨 SweetBites – UI/UX Design

SweetBites is a modern dessert ordering mobile application designed in Figma.

## Features
- Clean and modern UI
- User-friendly navigation
- Responsive mobile design
- Interactive prototype
- Wireframing
- High-fidelity UI
- Auto Layout
- Reusable Components

## Tools Used
- Figma
  
## Screens Included
- Splash Screen
- Home Screen
- Product Details
- Cart
- Checkout
- Profile
